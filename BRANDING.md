# Brand guide

## Product statement

Glyph Forge turns text, pixels, and moving images into adaptive terminal glyphs.

Preferred short description:

> Adaptive image, video, and stream rendering for terminals.

## Voice

- Precise and direct.
- Confident about tested behavior, careful about platform-dependent results.
- Welcoming to non-technical users without obscuring advanced controls.
- Concrete verbs: convert, render, stream, inspect, export.
- No unverifiable superlatives, performance promises, or mystical personas in
  product documentation and error messages.

## Naming

- Product and prose: `Glyph Forge`.
- Python distribution: `glyph-forge`.
- Python package: `glyph_forge`.
- Executable: `glyph-forge`.
- Image command group: `imagize`.
- Text command: `bannerize`.

Use lowercase `glyph` when referring to a character or rendered stream, and the
capitalized product name only for the project.

## Visual direction

The product is terminal-first. Examples should remain legible without color and
must have an ASCII fallback. Prefer compact, high-contrast samples generated by
the current release over checked-in binary screenshots or third-party media.

Color should communicate structure and status, not carry meaning alone. Avoid
emoji in machine-readable output, default error messages, and compatibility
documentation.
